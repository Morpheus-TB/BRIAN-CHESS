# A Little Question for Tabitha

A playful, single-page feelings questionnaire with a polished Tailwind CSS design. It invites someone to share their first impression, what they value in a person, their favorite kind of conversation, whether they are open to getting to know you, and a rating out of 10. Answers appear in a final recap and are not sent or stored.

## Run it

Open `index.html` in a browser. An internet connection is needed to load Tailwind CSS and the Google Fonts used by the page.
